# Документационный выпуск — 8 сентября 2026

README, путеводители, SVG-обложки и реальные локальные скриншоты публикуются отдельно от runtime. Снимки показывают дату и состояние локального preview, а не подтверждённый production. StarCRM/StarMarket не входят в эту витрину.

## Безопасная публикация

Основой каждого пакета служит актуальный GitHub commit. Только разрешённые файлы добавляются новым коммитом; локальные feature-ветки и чужие изменения не сливаются. Архивы, недоступные репозитории и проекты без remote пропускаются.

Новый read-only deployment-scope проверяет полный диапазон push через GitHub Compare API. Для workflow_run используется before/after исходного check suite, не только последний commit. Ошибка API, diverged history или 300 и более файлов блокируют deployment до review. Переименование runtime-файла в docs всё равно считается изменением runtime.

Однократное исключение для внедрения guard ограничено точным исходным SHA и перечисленными файлами этого документационного выпуска. Следующие изменения workflow не игнорируются. Обычные CI/security jobs и существующие approvals сохраняются. Concurrency перенесена на deployment job: проверка документации не отменяет текущую выкладку.

Проверка политики: `node --test scripts/test-repository-deployment.mjs`. Сам фильтр не устраняет остальные риски существующих deployment-скриптов и не доказывает состояние серверов. Полные локальные receipts не публикуются.
