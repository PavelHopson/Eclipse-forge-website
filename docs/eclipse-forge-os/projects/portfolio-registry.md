## Portfolio decisions

- The public flagship is Eclipse Forge OS, not every repository at once.
- A project enters the runtime graph only with an owner, versioned contract, security
  boundary and release path.
- `not_assessed` means exactly that; it is not a negative quality judgment and cannot be
  converted into a live/beta/production claim.
- Incubators should receive a deliberate `promote`, `merge`, `maintain as case study` or
  `archive` decision. Repository count is not a growth metric.
