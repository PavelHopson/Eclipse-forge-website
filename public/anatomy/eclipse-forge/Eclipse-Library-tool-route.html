Как читать сцену

Выберите запрос в каталоге. Курсор-жетон проходит через станцию входа, затем останавливается на проверке разрешений перед любым внешним действием.

Статус источника: проверено только для каталога. Eclipse Library открывает официальный источник и не устанавливает инструмент автоматически; точный transport и receipt в текущем маршруте не подтверждены кодом.
