# AI Project Production Readiness Checklist

Пять блоков, которые стоит проверить до запуска AI-функции для реальных пользователей.

## 1. Ценность и границы

- [ ] Названа конкретная проблема и пользовательский сценарий.
- [ ] Есть измеримый результат и исходная точка для сравнения.
- [ ] Ясно, что AI не делает и где нужен человек.
- [ ] В интерфейсе виден следующий шаг, ошибка объяснима, действие можно отменить.

## 2. Данные и права

- [ ] Для каждого источника известны provenance, лицензия и допустимое использование.
- [ ] Для персональных, голосовых и биометрических данных получено явное согласие.
- [ ] Зафиксированы retention, удаление, экспорт и доступ сотрудников.
- [ ] Секреты и production-данные не попадают в промпты, логи и тестовые наборы.

## 3. AI-качество

- [ ] Есть versioned eval-набор с реальными сценариями, включая ошибки и злоупотребления.
- [ ] Измеряются точность, groundedness, latency, стоимость и доля human fallback.
- [ ] Утверждения связаны с evidence; неопределённость показывается пользователю.
- [ ] Смена модели, промпта или tool-набора требует повторной проверки.

## 4. Security и permissions

- [ ] Проверены authentication, authorization, rate limits и tenant isolation.
- [ ] Недоверенный контент из сайтов, файлов и tool output изолирован от system instructions.
- [ ] Внешние действия используют allowlist, минимальные scopes и ручной approval.
- [ ] Зависимости закреплены lockfile; install scripts, telemetry и лицензии проверены.
- [ ] Для URL/import закрыты SSRF, path traversal, unsafe MIME и oversized payloads.

## 5. Эксплуатация и rollback

- [ ] Логи помогают расследовать сбой, но не содержат PII, токены и полный prompt content.
- [ ] Есть budgets, timeouts, retries, circuit breaker и понятный fallback.
- [ ] Алерты привязаны к владельцу и конкретному runbook.
- [ ] Feature flag или rollback возвращает предыдущий безопасный путь.
- [ ] Перед production выполнены typecheck, tests, build, security review и mobile/desktop QA.

## Решение

- **Можно запускать:** Critical/High риски закрыты, владелец и rollback назначены, метрики готовы.
- **Canary:** ценность подтверждена, но остаются ограниченные операционные риски; доступна малая группа и быстрый rollback.
- **Не запускать:** нет прав на данные, доказательств качества, разграничения доступа или безопасного отката.

Источник: Eclipse Forge. Чек-лист не заменяет отдельный legal, privacy или security audit.
