# demo-video — демо-ролики студии для клиентов

Свой «Loom» для пилота студии: записываем экран прямо в браузере, отправляем клиенту ссылку на нашем домене, получаем уведомление в Telegram, когда он открыл ролик.

Node 20+, без зависимостей и без ffmpeg: Chrome и Edge сразу пишут MP4 (H.264 + AAC), который играет и на iPhone. Если браузер умеет только WebM, сохраняется WebM.

## Как пользоваться

1. Открыть `https://<домен>/record` в Chrome, Edge или Яндекс Браузере на компьютере. Один раз ввести ключ студии.
2. Вписать «Для кого» и название, оставить «Мой голос», при желании включить «Моё лицо в углу».
3. «Начать запись» → выбрать «Весь экран» (так в запись попадёт окно камеры) → показать сайт → «Остановить».
4. Посмотреть запись → «Получить ссылку для клиента» → «Скопировать» и отправить клиенту.
5. Когда клиент откроет ссылку, в Telegram придёт: «Гостевой дом «Дюна»: открыли демо «…» (всего просмотров: 1)». Повторное открытие с того же адреса в течение 30 минут не считается, а сообщение по одному ролику приходит не чаще раза в 15 минут. Превью ссылки в мессенджере просмотром не считается.

Внизу страницы записи — список роликов с числом просмотров и кнопкой «Удалить» (ссылка у клиента после этого перестаёт работать).

## Настройки (окружение)

| Переменная | Обязательно | По умолчанию | Что это |
|---|---|---|---|
| `DEMO_ADMIN_TOKEN` | да | — | Ключ студии, случайная строка от 24 символов (`openssl rand -hex 24`) |
| `DEMO_PUBLIC_BASE` | да на сервере | `http://127.0.0.1:8788` | Адрес, из которого строятся ссылки, например `https://demo.eclipse-forge.ru` |
| `DEMO_DATA_DIR` | нет | `server/demo-video/.data` | Где лежат ролики и их описания |
| `DEMO_MAX_MB` | нет | `500` | Предел размера одного ролика |
| `DEMO_CONTACT_URL` | нет | `https://t.me/EclipseHopson` | Куда ведёт кнопка «Обсудить в Telegram» |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | нет, только вместе | — | Уведомления о просмотрах. Без них — строка в журнал сервиса |
| `DEMO_PORT`, `DEMO_HOST` | нет | `8788`, `127.0.0.1` | Где слушать. `DEMO_HOST` не менять: сервис должен быть доступен только через Caddy |

Можно взять того же бота и чат, что у `lead-relay`.

## Включение на VPS (делает Павел)

1. Поддомен `demo.eclipse-forge.ru` → A-запись на VPS.
2. Файл `/etc/ef-demo-video.env`, права `600`:
   ```
   DEMO_ADMIN_TOKEN=...          # openssl rand -hex 24
   DEMO_PUBLIC_BASE=https://demo.eclipse-forge.ru
   DEMO_DATA_DIR=/var/lib/ef-demo-video
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```
3. Код в `/srv/ef-demo-video/` (`server.mjs`, `main.mjs`, `record.html`, `watch.html`), папка данных:
   `install -d -o www-data -g www-data -m 750 /var/lib/ef-demo-video`
4. systemd-юнит `/etc/systemd/system/ef-demo-video.service`:
   ```
   [Service]
   EnvironmentFile=/etc/ef-demo-video.env
   ExecStart=/usr/bin/node /srv/ef-demo-video/main.mjs
   Restart=on-failure
   User=www-data
   [Install]
   WantedBy=multi-user.target
   ```
   `systemctl enable --now ef-demo-video`
5. Caddyfile:
   ```
   demo.eclipse-forge.ru {
       reverse_proxy 127.0.0.1:8788
   }
   ```
   `systemctl reload caddy`
6. Проверка: `curl https://demo.eclipse-forge.ru/healthz` → `{"ok":true}`; записать короткий ролик, открыть ссылку с телефона, дождаться уведомления.

Место на диске: ролик 5 минут ≈ 100–150 МБ. Старые ролики удалять кнопкой в списке.

## Защита

- Загрузка, список и удаление — только с ключом студии (сравнение за постоянное время).
- Ссылка на ролик — 12 случайных символов, ролики не индексируются (`noindex`), страница записи не встраивается в чужие сайты.
- Принимаются только `video/mp4` и `video/webm`, размер ограничен, неудачная загрузка не оставляет файлов.
- Просмотры: адрес клиента берётся из заголовка Caddy только для соединений с локального адреса; счётчик и уведомления защищены от накрутки и спама.
- Встроенных скриптов нет, CSP запрещает чужие и inline-скрипты; HSTS и Permissions-Policy выставлены.
- Название и имя клиента экранируются на странице, в Telegram уходят простым текстом.
- Ключ хранится в браузере студии (localStorage). На чужом компьютере не вводить; при утечке — сменить `DEMO_ADMIN_TOKEN` и перезапустить сервис.
